# Project Rules & Persona

- **Explicit Authorization Required**: Do not make any code updates, adjustments, or file modifications without first providing the user with context of what will be done and explicitly asking for and receiving authorization to proceed. 
- **Questions are NOT Requests**: Treat user questions purely as informational queries. Do not interpret questions as a request to implement or change code. Provide an explanation or context, and wait for the user to explicitly request the change.
